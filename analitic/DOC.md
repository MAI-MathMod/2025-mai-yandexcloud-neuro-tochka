# Документация проекта: RAG-система для ответов на вопросы о поступлении в МАИ

## Общее описание
Проект представляет собой RAG (Retrieval-Augmented Generation) систему, построенную на базе YandexGPT, для ответов на вопросы абитуриентов о поступлении в Московский Авиационный Институт (МАИ).

## Метрики оценки RAG-системы

### Faithfulness (достоверность)
Оценивает, насколько ответ соответствует предоставленному контексту. Метрика проверяет:
- Фактическую точность информации
- Отсутствие вымышленных или необоснованных утверждений
- Соответствие ответа информации в контексте

Формула оценки:
```
faithfulness = 1.0 - (количество неверных утверждений / общее количество утверждений)
```

### Answer Relevance (релевантность ответа)
Оценивает, насколько ответ соответствует заданному вопросу:
- Полнота ответа
- Прямое соответствие вопросу
- Отсутствие нерелевантной информации

Формула оценки:
```
answer_relevance = 1.0 - (количество нерелевантных частей / общая длина ответа)
```

### Context Relevance (релевантность контекста)
Оценивает качество извлеченного контекста:
- Релевантность контекста вопросу
- Полнота контекста
- Отсутствие избыточной информации

Формула оценки:
```
context_relevance = 1.0 - (количество нерелевантных частей контекста / общая длина контекста)
```

### Answer Correctness (правильность ответа)
Сравнивает ответ с эталонным (ground truth):
- Семантическое соответствие
- Фактическая точность
- Полнота информации

Формула оценки:
```
answer_correctness = similarity(answer, ground_truth)
```

## Структура проекта

### Основные файлы
1. `build_and_run_rag.py`
   - Создает и настраивает ассистента YandexGPT
   - Загружает и индексирует данные для RAG-системы
   - Настраивает параметры ассистента и системы поиска

2. `ragas_evaluation_yandex.py`
   - Оценивает качество работы RAG-системы
   - Использует метрики:
     - faithfulness (достоверность)
     - answer_relevance (релевантность ответа)
     - context_relevance (релевантность контекста)
     - answer_correctness (правильность ответа)
   - Поддерживает параллельную обработку запросов
   - Включает обработку ошибок и таймауты

### Обработка данных
1. `process_data.py`
   - Обрабатывает исходные данные (удаляем поля ненужные, стикеры и прочие не текст сообщения отсеиваем, нормализацию производим)

2. `convert_to_md.py`
   - Конвертирует данные в формат Markdown
   - Подготавливает структурированные документы

### База знаний

1. `parsed_data` - данные с сайтов
2. `markdown_data` - переданные данные из чатов приемки МАИ 2021б 2022б 2023б 2024 годов

### Тестовые данные

1. `data_for_vectorize/`
   - Содержит тестовые Q&A пары в формате JSON
   - Включает вопросы, ответы, контекст и эталонные ответы
   - Структура данных:

     ```json
     {
         "qa_pairs": [
             {
                 "question": "...",
                 "answer": "...",
                 "context": "...",
                 "ground_truth": "..."
             }
         ]
     }
     ```

   - Параметры тестовых данных:
     - `question`: вопрос, на который нужно ответить
     - `answer`: ответ, сгенерированный RAG-системой
     - `context`: контекст, использованный для генерации ответа
     - `ground_truth`: эталонный (правильный) ответ, с которым сравнивается сгенерированный ответ. Это "золотой стандарт", созданный экспертами и используемый для оценки качества работы системы.
