Документы для заселения в общежитие МАИ
Основные документы
Три копии паспорта (страницы 2, 3, 5); для иностранных граждан перевод паспорта (нотариально заверенный)
Копия извещения о зачислении в институт с предоставлением места в общежитии
Копию приписного свидетельства (военного билета) с отметкой о снятии с воинского учета по месту жительства
Фото 3х4 или 4х6 (2 шт.)
Нотариально заверенное согласие законных представителей на заселение в общежитие МАИ несовершеннолетних граждан

Медицинские документы
Документ о проведении профилактической иммунизации в рамках Национального календаря прививок по эпидпоказаниям (сертификат о профилактических прививках с указанием даты проведения вакцинации против: дифтерии, коклюша, столбняка (АКДС), кори (ЖКВ), краснухи, эпидемического паротита (ЖПВ), гепатита В, туберкулёза (БЦЖ))
Медицинскую справку формы № 086-у (врачебное профессионально-консультативное заключение)
Флюорографическое исследование лёгких об отсутствии заболевания туберкулёзом
Медицинскую справку с заключением врача дерматовенеролога об отсутствии противопоказаний для проживания в общежитии с отметкой бактериоскопического анализа на ЗППП, результат исследования крови на сифилис и по желанию, на добровольной основе медицинское освидетельствование на ВИЧ-инфекцию
Результат тестирования на коронавирусную инфекцию (COVID-19) сроком давности не позднее 3-х дней (рекомендовано)

Примечание для иностранных граждан
Иностранные граждане дальнего и ближнего зарубежья должны предоставлять все медицинские заключения, включая сертификаты профилактических прививок, с нотариально заверенным переводом на русский язык.
